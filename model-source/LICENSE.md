# Minecraft model resources

The model and blockstate JSON resources encoded in `26.3.json` and the derived
`renderer/generated/block-models.mjs` originate from Minecraft Java Edition 26.3.
Copyright belongs to Mojang AB and Microsoft. These resources are **not** covered
by this repository's MIT code license.

`source.json` records the official source, verified client archive SHA-1 and
extraction scope. The compact source container preserves original file bytes
as base64 and supports deterministic offline rebuilding. The client archive,
game code and entity renderer implementations are not distributed here.
